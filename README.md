A Python-based Investment Portfolio Tracker that calculates invested amounts, sample market values, profit/loss percentages, and exports portfolio summaries to a CSV file.
# Datheon Python Programming Internship

## Task 2: Investment Portfolio Tracker

### Project Description
I developed an Investment Portfolio Tracker using Python. This project calculates the total invested amount, market value, profit or loss, and gain/loss percentage for stock investments.

### Technologies Used
- Python
- CSV File Handling
- Basic Python Calculations

### Features
- Enter stock ticker symbols.
- Enter purchase prices and quantities.
- Calculate total invested amount.
- Calculate market value using sample stock prices.
- Calculate total gain or loss and percentage.
- Export the portfolio summary to a CSV file.

### How I Developed the Project
1. Created a Python file named `portfolio.py`.
2. Collected stock symbols, purchase prices, and quantities from the user.
3. Used sample market prices to calculate the current market value.
4. Calculated the total investment, gain/loss, and percentage.
5. Exported the results to `portfolio_summary.csv`.
6. Tested the program to verify the calculations.

### Sample Output
- Total Invested: $1000.00
- Total Market Value: $1150.00
- Total Gain/Loss: $150.00
- Total Gain/Loss Percentage: 15.00%

*Note: The market prices are sample values used for practice, not live stock prices.*
